# Pre-press checklist

- Size in mm matches approved spec; SVG viewBox equals physical size.
- Safe margin respected; cut/fold marks present; hand-filled fields on light background.
- Zero production notes inside printable art (specs live in manifest).
- Logo and QR embedded from real repo files with recorded hashes.
- Copy matches approved sources verbatim; pending fields explicit (`______`, never invented).
- PDF pages at final size; PNG previews at 300 dpi equivalent.
- Manifest: files, dimensions, fonts, hashes, method, cost, QC, pending list.
