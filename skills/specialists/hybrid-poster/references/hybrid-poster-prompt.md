# Hybrid poster prompt template

Order blocks in English: RESULT (finished poster, aspect ratio, internal draft) → REFERENCES (identity plate controls character; logo placement-only) → IDENTITY (preserve exactly, no recolor, no extra costume) → LAYOUT (ticket hierarchy, safe margins) → STYLE (palette, typography mood) → EXACT TEXT (verbatim list only) → QR SLOT (empty white square, quiet zone, no fake matrix) → CONSTRAINTS → OUTPUT (native size).

Post-production checklist: OCR vs verbatim list · identity vs plate · logo 1:1 restore on drift · real QR paste · manifest (model, params, request, hashes, cost, QC) · status `draft_internal_review`, never print-ready.
